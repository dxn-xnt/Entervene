# Archived prediction evidence and proposals

These dated records preserve earlier scope audits, experiments, implementation decisions, and acceptance evidence. Their status and metrics do not supersede the [current prediction reference](../../PREDICTION_SYSTEM.md).

- `CURRENT_TERM_V3_SCOPE_4C.md` and `SHS_DATA_FITNESS_4D.md` preserve the inspected curriculum and workbook inventories; their database counts describe the audit date.
- `PREDICTION_STRATEGY_4E.md` and `V3_BASELINE_BENCHMARK_4F.md` preserve reproducible legacy-target experiments. Their metrics measure the mixed/reconstructed target corrected by [4H](../../V3_TARGET_INTEGRITY_4H.md), not official-target accuracy.
- `DEVELOPMENT_PREDICTION_ACCEPTANCE_4M.md` preserves isolated demo API, artifact, and test acceptance results, plus its unresolved browser and artifact-provisioning gates.
- `TICKET-2026-PREDICTION-EVIDENCE-STAGE-1-REPORT.md`, `TICKET-2026-PREDICTION-EVIDENCE-STAGE-1-5.md`, and `TICKET-2026-PREDICTION-EVIDENCE-STAGE-6-REPORT.md` preserve the Phase 1 baseline, approved concurrency/source decisions, and dated acceptance results. Active follow-up is in the [Phase 1 ticket](../../tickets/TICKET-2026-PREDICTION-EVIDENCE-PHASE-1.md).

- [TICKET-2026-ENROLLED-STUDENT-SCORING.md](TICKET-2026-ENROLLED-STUDENT-SCORING.md) proposed an event-driven enrolled-cohort scoring lifecycle. Its cohort counts, accuracy assertions, and implementation status were not established by this audit; the current script and development route follow distinct paths. The proposal remains useful context for a future bounded cohort workflow.
